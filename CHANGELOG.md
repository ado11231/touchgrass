# Changelog

## [0.1.0] - 2026-08-25

The first release of touchgrass, a local tracker for active time in development tools.

### Included

- Track active processes and credit time to focused tools.
- Ignore idle time and save daily totals locally.
- Show a year heatmap, summary cards, and today's time by tool.
- Start tracking at login on macOS and Linux.
- Configure tracked tools and view command help from the CLI.
